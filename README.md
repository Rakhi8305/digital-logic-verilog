# 🔷 Digital Logic Verilog

This repository contains basic digital logic circuits implemented using Verilog HDL and simulated using EDA Playground.

---

## 🔹 Basic Gates

### 🔸 AND Gate

* Logic: y = a & b
* Output is 1 only when both inputs are 1

### 🔸 OR Gate

* Logic: y = a | b
* Output is 1 when at least one input is 1

---

## 🔹 Simulation

All circuits are simulated using EDA Playground.
Waveforms verify correct functionality.

---

## 🔹 Tools Used

* Verilog HDL
* EDA Playground
* EPWave
